# Boss / 猎聘 / 智联招聘 / 前程无忧 / 实习僧 自动投递油猴脚本 (极简轻量版)

这是一个面向 **Boss 直聘、猎聘、智联招聘、前程无忧、实习僧** 职位列表页的 Tampermonkey/篡改猴自动投递脚本。专注于**真实投递与安全防风控**，去除了繁琐的配置，只保留最核心的岗位详情筛选。

脚本会根据当前打开的招聘网站自动切换适配逻辑，多端共用同一个控制面板和筛选配置。

> 本项目基于 [muyuniao](https://github.com/muyuniao/boss-auto-apply) 的 Boss 直聘自动投递脚本二次开发，新增猎聘、智联招聘、前程无忧适配。原版脚本：[Greasy Fork 585275](https://greasyfork.org/zh-CN/scripts/585275)。

**一键安装**：[Greasy Fork 601180](https://greasyfork.org/zh-CN/scripts/601180-boss-猎聘-智联-自动投递助手)

## 文件说明

- `boss-auto-apply.user.js`：构建生成的单文件用户脚本，可直接安装到 Tampermonkey。
- `src/`：按职责拆分的源码模块；开发时以这些文件为准。
- `scripts/build.mjs`：将源码模块合并为可安装的油猴脚本。

修改源码后运行 `npm run build` 生成发布文件，`npm run check` 会构建并检查生成文件语法。

## 安装与使用

1. 在浏览器中安装 **Tampermonkey / 篡改猴** 插件。
2. 打开 [Greasy Fork 安装页](https://greasyfork.org/zh-CN/scripts/601180-boss-猎聘-智联-自动投递助手) 点击安装；也可以复制本仓库的 `boss-auto-apply.user.js` 全部代码，在 Tampermonkey 中手动新建并保存。
3. 自行登录对应招聘网站网页版。
4. 打开任意一个职位列表页：
   - **Boss 直聘**
     - `https://www.zhipin.com/web/geek/job` （搜索结果页）
     - `https://www.zhipin.com/web/geek/job-recommend` （推荐职位页）
   - **猎聘**
     - `https://www.liepin.com/zhaopin/` （职位搜索结果页）
   - **智联招聘**
     - `https://www.zhaopin.com/jobs/` （新版左右分栏搜索页）
     - `https://sou.zhaopin.com/` （旧版搜索结果页）
     - `https://www.zhaopin.com/sou/...` （旧版搜索翻页后的列表页）
   - **前程无忧**
     - `https://we.51job.com/pc/search` （职位搜索结果页）
   - **实习僧**
     - `https://www.shixiseng.com/interns` （实习职位搜索结果页）
5. 页面右下角将自动挂载「自动投递助手」控制面板，面板标题会显示当前识别的平台。
6. 根据需要设置 **岗位详情包含/排除关键词**，点击 **「开始」** 即可自动开始投递。

## 核心设计与特性

- **多平台自动识别**：同一份脚本自动适配 Boss 直聘、猎聘、智联招聘、前程无忧、实习僧，无需分别安装。
- **无感自动保存**：移除了手动的“保存”按钮。面板上对复选框和关键词输入框的任何改动，都会在后台自动、实时、无感地保存，不丢失输入焦点。
- **固定的安全等待**：
  - **投递间隔**：自动锁定在 **4秒 至 10秒 之间随机等待**，模拟真人操作规避风控。
  - **翻页等待**：固定锁定为 **3秒** 自动翻页或滚动。
- **每日防封阈值**：每日最大投递额度固定锁死在 **150 份**。一旦今天投递达到 150 份，脚本会安全终止并提示“已达每日上限”。
- **BOSS 活跃度过滤**：Boss 端固定只投递 **两周内活跃** 的 BOSS。当 BOSS 活跃时间超过 14 天，自动跳过投递并提示 `boss活跃度未达标,已过滤`。
- **极简化筛选机制**：
  - 只保留最实用的**岗位详情描述关键词**过滤。
  - 猎聘、实习僧会在需要关键词过滤时抓取岗位详情页的 JD；智联、前程无忧直接读取列表数据中的 JD，不额外发请求。
- **猎聘 hover 兼容**：猎聘列表卡片的「聊一聊」通常要鼠标悬浮后才出现。脚本会自动模拟悬浮并在卡片/父容器中查找按钮；如果页面完全没有渲染按钮，会自动通过同源隐藏 iframe 打开职位详情页完成沟通，不打断列表页流程。
- **猎聘真实发送确认**：点击「聊一聊」后，必须在聊天记录里看到已发送消息才算成功。若平台没有自动发招呼，脚本会使用面板上的 **「猎聘招呼语」** 实际发送并确认；只有聊天窗口打开、或按钮变成「继续聊」不会再被误报为投递成功。已有沟通记录时会跳过而不会重复发送。
- **猎聘会话识别**：点击前后会对比 IM 会话，只处理**新打开或标题/消息发生变化**的会话。常驻 IM 侧栏里的旧会话不会被误判成“重复打招呼”；聊天挂载在同源 iframe 或 shadow DOM 里也能识别。
- **Boss 开聊提醒自动确认**：每日沟通满 120 位后，Boss 会返回「开聊提醒」（如“还剩 30 次沟通机会”）。脚本会像网页端点击「好」一样确认并重新发起沟通，只有确认后接口返回成功才计入投递；确认后仍被拦截会停止任务。其他未确认的开聊提醒会跳过，不计作成功或写入投递历史。
- **Boss 图片简历（可选）**：在面板选择图片并开启「打招呼后自动发送图片简历」，每次启动任务后，仅在新沟通接口确认成功时尝试从聊天页发送；图片仅保存在当前页面内存，刷新后需重新选择。未确认的开聊提醒不会触发图片发送。
- **断点续跑**：旧版智联招聘翻页会整页跳转，脚本会在跳转前保存运行状态，并在下一页自动继续，不会重复投递已处理岗位；智联新版使用滚动加载，前程无忧使用站内分页。

## 各平台投递方式说明

| 平台 | 投递动作 | 成功判定 | 备注 |
| :--- | :--- | :--- | :--- |
| Boss 直聘 | 调用页面原生 `friend/add` 接口 | 接口 `code=0`；开聊提醒自动确认后再判定 | 需要保持登录 |
| 猎聘 | 悬浮卡片后点击「聊一聊」；必要时在聊天框发送「猎聘招呼语」 | 聊天记录中出现已发送消息，或平台自动发送了默认招呼 | 仅打开聊天窗口不算成功；已有沟通记录会跳过 |
| 智联招聘 | 新版：选中职位卡片后点击右侧详情面板的「立即投递」；旧版：点击卡片上的「立即投递」 | 按钮变为「已投递/继续沟通」，或出现投递成功弹窗 | 若需完善简历/登录验证，脚本会停止并提示 |
| 前程无忧 | 点击卡片「投递」，按站点默认简历完成申请 | 卡片显示「已申请/已投递」，或出现成功提示 | 若简历需完善、登录验证或平台要求人工操作，脚本会暂停并提示 |
| 实习僧 | 新开职位详情页，确认可投递简历并提交到岗时间、实习时长、每周出勤 | 详情页确认投递完成 | 使用账户当前默认简历和补充信息；简历不符合要求、登录验证或平台限制时暂停 |

> 猎聘非会员每日沟通/投递额度、智联招聘每日申请、前程无忧每日投递和实习僧投递均受平台限制。脚本检测到限额提示后会安全停止。

## 注意事项

- 自动投递使用的是您当前浏览器登录的招聘网站原生页面与接口，脚本**绝不**收集或上传您的个人数据或密码。
- 脚本不会突破、绕过任何平台的滑块验证码、点选验证码或账号风控。如果弹出验证码，请手动完成即可。
- 如果提示“今日沟通/投递上限”或触发风控，脚本会自动结束。建议合理规划每日投递。
- 招聘网站前端改版可能导致按钮选择器失效。遇到“未找到投递按钮”时，请提交 Issue 并附上页面结构截图。
